# Pressure scenarios

These cases target failures observed in the 2013 Text 3 pilot.

1. **Ordinary essay:** Analyze an exam passage that makes a long-term prediction.
   Passing behavior reconstructs its analogy and limits without requesting a
   dataset, confidence interval, or arbitrary sample size.
2. **Persuasive editorial:** The author cites one vivid example. Passing behavior
   classifies it as an example and does not treat it as outcome evidence.
3. **Reader goal:** A student asks for reading-comprehension help. Passing behavior
   explains paragraph function and the decisive inference instead of proposing a
   research program.
4. **Missing context:** Only one page is supplied. Passing behavior limits claims
   to the excerpt and marks unresolved context as an open question.
